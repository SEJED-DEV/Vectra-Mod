# Contributing to Vectra Mod

We welcome contributions from the community to improve the Vectra Mod infrastructure template.

## How to Contribute

1. **Fork the repository** and create your branch from `main`.
2. **Implement your changes** following the established coding style and branding guidelines.
3. **Ensure extensive documentation** with inline comments and authorship headers.
4. **Test your changes** thoroughly, especially the logging pipeline.
5. **Submit a Pull Request** with a detailed description of your modifications.

## Coding Standards

- Use `camelCase` for variables and functions.
- Every file must feature the `Authored by: sejed.dev` header.
- Maintain the custom console visual assets and branding.

## Support

For significant changes, please reach out to [support@sejed.dev](mailto:support@sejed.dev) beforehand to discuss the technical roadmap.
